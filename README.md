## **Sistema de Estoque EPISODE**

**Descrição:**

Este sistema Java foi desenvolvido para gerenciar o estoque de uma loja de roupas fictícia chamada EPISODE. Ele permite o cadastro, edição, exclusão e consulta de produtos e clientes, além de realizar a venda de produtos. As informações são armazenadas em arquivos de texto para facilitar a compreensão e manutenção.

**Funcionalidades:**

* **Cadastro de produtos:**
  * Código
  * Nome
  * Preço
  * Quantidade em estoque
  * Gênero (masculino, feminino, unissex)
  * Classe (camiseta, calça, etc.)
* **Edição de produtos:** Atualização de todos os dados do produto.
* **Exclusão de produtos:** Remoção completa do produto do estoque.
* **Consulta de produtos:** Busca por código, nome, gênero ou classe.
* **Cadastro de clientes:**
  * CPF
  * Email
  * Nome
  * Gênero
  * Quantidade de compras (inicializada em zero)
* **Edição de clientes:** Atualização de todos os dados do cliente.
* **Exclusão de clientes:** Remoção completa do cliente do sistema.
* **Consulta de clientes:** Busca por CPF, nome, email ou gênero.
* **Venda de produtos:** Realização de vendas, atualizando a quantidade em estoque.
* **Menu principal:** Interface intuitiva para acessar todas as funcionalidades.
* **Versão do sistema:** Informação sobre a versão atual do sistema.

**Tecnologias Utilizadas:**

* **Java:** Linguagem de programação principal.
* **Arquivos de texto:** Armazenamento de dados.

**Pré-requisitos:**

* **Java Development Kit (JDK):** Instale a versão mais recente do JDK em seu sistema.
* **Editor de texto:** Use um editor de código como o Visual Studio Code, IntelliJ IDEA, NetBeans ou Eclipse.

**Estrutura de Arquivos:**

* `AcoesSistemaProduto`: Contém os arquivos de código fonte de manejo de produtos.
* `AcoesSistemaCliente`: Contém os arquivos de código fonte de maneko de clientes.
* `AcoesSistemavenda`: Contém os arquivos de código fonte para realização da Venda.
* `Menu`: Contém o arquivo de código fonte para criação de um menu.
* `Sobre`: Contém os arquivos de código fonte parac criação de uma janela informativa.
* `Produtos.txt`: Contém os dados do produto.
* `Clientes.txt`: Contém os dados cliente.
* `README.md`: Este arquivo.
